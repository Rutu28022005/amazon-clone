# Amazon Clone

A simple Amazon e-commerce website clone built using only HTML, CSS, and JavaScript.

## Features

- Browse products with images, titles, and prices
- Add products to a shopping cart
- View and update cart items
- Responsive and modern design

## How to Use

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Explore products and use the cart functionality.

## Technologies

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript 

---

This project is a frontend-only static site and requires no backend or setup. Just open and shop!
